# Current task audits

New task-specific verification reports live here, adapted from
[moorkyz-template](https://github.com/Moorky/moorkyz-template)'s tracked
`.audits/` hierarchy. Generate a report with either root launcher:

```powershell
node .\moorkyz audit "task title"
```

Fill the [audit template](../src/docs/AUDIT_TEMPLATE.md) with actual commands and
observed results before committing. An agent self-audit is not independent
security review, accessibility certification, deployment or release approval.

Older operations records and historical implementation audits are retained in
this directory by the pending workspace reorganization. Do not rewrite their
evidence or treat retired product requirements as current.
