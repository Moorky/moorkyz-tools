## 1. Request and outcome

- Requested behavior: one reusable intelligent search per read-only terminal; default five hits configurable from one through ten; selected line/hit file and directory icons; selectable full/time-only timestamps.
- Implemented behavior: local asynchronous literal AND search, phrases, exclusions and exact level filters; newest run folders first; cancellation/debounce; every integer limit supported and persisted; full UTC dates remain on disk. Live records retain combined/error-file physical line metadata through truncation and timestamp switches. Selected lines open a read-only context excerpt with the exact physical line selected; the directory action uses Explorer selection. Search and preview collapse together with existing reduced-motion-aware transitions.
- Acceptance criteria and evidence: native fixtures exercise all ten limits, default five, persisted seven, full/compact display and unchanged saved bytes, phrase/case/AND/exclusion/level semantics, cancelled stale queries, Enter/Escape, precise combined/error source selection, hidden capture, junction rejection, missing sources, malformed settings and failed preference saves. Actual GUI/XAML/C# compilation and responsive native launcher invocation passed.
- Intentional exclusions: no network/AI search service, regex execution, arbitrary project file indexing, external-editor integration, log rewriting, automatic services, installation, deployment, independent desktop app instrumentation or archived service-log ingestion. The source window is explicitly a context excerpt, not an unrestricted full-file editor.
- Relevant decisions/contracts: [root contract](../AGENTS.md), [current product decisions](../src/docs/decisions/decision-register.md), [GUI guide](../src/.moorkyz/gui/README.md). Existing pinned Node/pnpm/Next/React/TypeScript stack and native WPF bootstrap are unchanged.

## 4. Risk and quality review

The new-file `--no-index --check` commands emit no whitespace diagnostics;
Git's exit status 1 denotes new-file content differences, not a whitespace error.

- Public contract, feature-default, and compatibility impact: both launcher namespaces retain their CLI behavior and use the same component/settings in the same checkout. Default five hits/full UTC time; compact is display-only. Search syntax and result ordering are documented. Recent stderr replay remains visible after large stdout bursts but now retains original source references rather than unsourced copies.
- Security, privacy, permissions, and secrets: only saved control-center command histories are searched; queries are not persisted. Source viewers redact again and are read-only. File/folder destinations are checked for root escape and reparse points; Explorer opens only on an explicit icon action. Ordinary filesystem checks are not a guarantee against hostile concurrent path replacement.
- Accessibility, keyboard, and reduced motion: named inputs/actions/results and polite status; native keyboard result selection; exact-line viewer is read-only and selectable; focus-visible themed results. Search content uses natural height and collapses with its terminal. Existing reduced-motion behavior is preserved. No independent certification claimed.
- Disabled-feature work/resource/network behavior: empty search starts no history scan; opening idle creates no runtime files. Preference files are created only after explicit user changes. No background network connection or implicit service startup.
- Error handling, cleanup, and recovery: cancelled/stale searches cannot replace current results; read errors do not masquerade as zero matches. Invalid settings fail explicitly; failed saves restore previous controls and emit an error. Missing source files show an explicit error. Timers, cancellations and owned source windows are disposed on close. Test directories are isolated synthetic fixtures and cleaned up.
- Dependency, performance, and regression exposure: no manifest/lockfile/stack changes. Search is line-based, cancellable between lines, returns at most limit plus one and stops after enough matches. History has no automatic rotation; a very large history/line can still be expensive to scan. Full logs never inherit the preview cap.
