- Intentional exclusions: no arbitrary performance score thresholds, no telemetry/AI/network integration, no new report dashboard or external editor, no colored escape codes/markup in raw logs/XML, no automatic retries of commands/clicks. Error interval averages in the UI are explicitly session-scoped, not silently computed from unrelated histories. Per-command reports have their own distinct sample scope. Days are the largest time unit; no guessed month/year lengths.
- Relevant decisions/contracts: [root contract](../AGENTS.md), [current product decisions](../src/docs/decisions/decision-register.md), [GUI usage guide](../src/.moorkyz/gui/README.md). ## 4. Risk and quality review

- Public contract, feature-default, and compatibility impact: logs gain compact reference fields after their level; old files are not rewritten. Recognized leading structured stdout levels are classified; stderr remains ERROR even if text claims TRACE. New report fields are additive; existing report duration consumers remain compatible. Display no longer shows a session-total clock. Seconds/minutes/hours promote at exactly 120, then days remain the largest unit.
- Security, privacy, permissions, and secrets: message text uses WPF `Run` construction, never `XamlReader` on messages, shell evaluation, ANSI interpretation or hosted processing. Redaction remains before persistence/display. Read-only controls remain selectable/copyable. Source icons continue to validate local destinations.
- Accessibility, keyboard, and reduced motion: color is redundant with textual levels/outcomes/categories; timestamp color never changes by severity. Existing terminal names, Ctrl+F, Enter/Escape and source keyboard focus retained. Rich document positions are resolved after attachment and tested against exact source lines. Existing reduced-motion/focus-return behavior remains passing.
- Disabled-feature work/resource/network behavior: no-error average explicitly unavailable until two real error samples; recent-error replay does not add interval samples. Opening idle remains non-mutating and starts no commands, services or network traffic.
- Error handling, cleanup, and recovery: invalid/negative/nonfinite durations throw instead of becoming zero; logging setup failure resets task time and exposes error/report status. Existing failed settings saves roll back choices and emit errors; missing files, bad reports, blocked destinations and links remain explicit failures. Empty flushes do not replace rich documents unnecessarily; rendering guards suppress spurious source selection changes.
- Dependency, performance, and regression exposure: no package/runtime/permission changes. Rich previews remain bounded; rebuilding a bounded rich document costs more than plain text and still needs production-volume review. Error clock/average mutations are under the existing output lock. Intervals use monotonic elapsed time, not wall-clock subtraction.
